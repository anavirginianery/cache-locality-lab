Cada cenário foi gerado a partir de uma distribuição de stack distance conhecida. Como a distribuição é conhecida, todo valor medido na carga tem um valor teórico correspondente, calculado sem simular nada. As linhas dos gráficos são o medido; os círculos vazados são o teórico. Se os dois coincidem, a carga saiu como foi pedida.

As curvas são de hit rate: a fração das requisições atendidas por um cache LRU de cada tamanho. O valor teórico vem direto da distribuição de stack distance, por hit(C) = (1 − P(∞)) · P(d < C) — acerta quem é reúso e cuja stack distance cabe no cache.

A conferência compara o hit rate medido com o teórico em cada tamanho de cache; o erro mostrado é o maior deles. Tolerância configurada: 0,020.

Curva de hit rate

SD baixa (β = 1,5) SD media (β = 1,0) SD alta (β = 0,5)

Quanto mais alta a curva, melhor o cache se sai. A carga de SD alta precisa de um cache muito maior para chegar ao mesmo hit rate das outras. O teto de todas é 1 − P(∞): objeto novo nunca pode ser acerto.

Acumulada da stack distance

Lê-se assim: no ponto x, a curva diz qual porcentagem dos reúsos tem stack distance menor que x — ou seja, quantos reúsos caberiam num cache de x objetos.

Distribuição da stack distance

SD baixa (β = 1,5) SD media (β = 1,0) SD alta (β = 0,5)

As faixas dobram de tamanho a cada passo (1, 2, 4, 8, …), porque a stack distance varia por ordens de grandeza.

Footprint

SD baixa (β = 1,5) SD media (β = 1,0) SD alta (β = 0,5)

Quantos objetos distintos aparecem numa janela de N requisições — os dois eixos em escala log. O footprint não é um parâmetro do gerador: ele emerge do nível de stack distance. A stack distance de um reúso é, por definição, a contagem de objetos distintos na janela entre dois pedidos ao mesmo objeto; então reúsos longos significam janelas com muitos objetos distintos. As duas curvas descrevem a mesma localidade por ângulos diferentes.

A última coluna é a resposta para "esta carga tem stack distance alta?" no único jeito que faz sentido: em relação ao tamanho de cache que você vai usar — a fração dos reúsos com SD menor que o cache, isto é, os que cabem.
